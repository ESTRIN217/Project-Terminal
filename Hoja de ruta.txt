Hoja de Ruta - Project-Terminal
================================

Estado actual: Implementación base funcional con entorno Debian vía PRoot,
integración Jetpack Compose, y pipeline de logging estructurado.

Objetivos y Prioridades
-----------------------

[P1] Migración a traducción nativa mediante strings.xml
  - Estado: Pendiente
  - Descripción: Reemplazar el sistema actual de traducciones basado en
    archivos JSON en assets/locales/ por el sistema nativo de Android
    mediante recursos strings.xml con calificadores de configuración
    (values-es/, values-fr/, etc.). Esto permite:
    * Aprovechar la selección automática de locale del sistema Android.
    * Reducir el código personalizado de gestión de idiomas (LocaleManager).
    * Facilitar la contribución de traducciones vía recursos estándar.
    * Compatibilidad nativa con Acceso a Ajustes de Idioma de Android 13+.
  - Tareas:
    1. Mapear todas las claves usadas en el sistema JSON actual.
    2. Crear values/strings.xml con valores por defecto (es_VE).
    3. Crear values-es/strings.xml y values-en/strings.xml con traducciones.
    4. Refactorizar LocaleManager para delegar en context.getString().
    5. Eliminar el sistema JSON legacy.

[P1] Integración completa del bypass W^X (libtermux_exec)
  - Estado: Implementación base (código C, build system, LD_PRELOAD configurado)
  - Descripción: Asegurar que libtermux_exec.so se copie al rootfs de Debian
    o se monte correctamente para que LD_PRELOAD funcione en el entorno
    PRoot. Verificar que los ejecutables ELF dentro del contenedor Debian
    sean correctamente redirigidos a través del linker de Android.
  - Tareas:
    1. Verificar montaje de /data_priv/lib/libtermux_exec.so en el rootfs.
    2. Probar execve() wrapper con binarios de Debian (bash, python, node).
    3. Agregar soporte para linker de 32 bits (linker) en termux_exec.cpp.
    4. Validar compatibilidad con Android 14+ y targetSdk 35+.

[P1] Soportes de PRoot y librerías nativas completas
  - Estado: Parcial (solo libproot.so arm64-v8a presente)
  - Descripción: Completar el conjunto de binarios nativos necesarios para
    el funcionamiento robusto del entorno virtualizado.
  - Tareas:
    1. Compilar o integrar libproot-xed.so (emulador PRoot extendido).
    2. Compilar o integrar libtalloc.so (asignador de memoria jerárquica).
    3. Compilar o integrar libbsdtar.so (extracción nativa de rootfs).
    4. Evaluar necesidad de libproot32.so para compatibilidad con binarios
       de 32 bits dentro del contenedor.
    5. Empaquetar binarios para todas las ABI objetivo.

[P2] Inicialización del pipeline de diagnóstico (DiagnosticPipeline)
  - Estado: Implementado (clases base, sinks, integración con DebugLogger)
  - Descripción: Activar y registrar los sinks del pipeline de logging
    asíncrono en los puntos de entrada de la aplicación. Integrar el
    pipeline con la UI de logs existente para visualización en tiempo real.
  - Tareas:
    1. Registrar LogcatSink, DiskSink y DebugLoggerSink en Application.onCreate().
    2. Integrar DiagnosticPipeline con la pantalla LoggerScreen.
    3. Agregar metadata de contexto (componente, sesión, PID) a los logs.
    4. Implementar rotación de archivos de log en DiskSink.

[P2] TerminalSurfaceState como envoltura Compose oficial
  - Estado: Implementado (TerminalSurfaceState, TerminalSurface, rememberTerminalSurfaceState)
  - Descripción: Migrar el uso directo de AndroidView+TerminalBridge en
    MainActivity para usar TerminalSurfaceState y TerminalSurface,
    promoviendo la reutilización y separación de responsabilidades.
  - Tareas:
    1. Refactorizar MainActivity para usar TerminalSurfaceState.
    2. Mover la lógica de teclas especiales a un componente Separado.
    3. Agregar pruebas unitarias para TerminalSurfaceState.

[P2] Soporte multi-ABI para librerías nativas
  - Estado: Pendiente
  - Descripción: Ampliar la compilación para incluir armeabi-v7a y x86_64
    además de arm64-v8a, permitiendo la ejecución en una gama más amplia
    de dispositivos Android (emuladores, tablets, dispositivos más antiguos).
  - Tareas:
    1. Habilitar abiFilters adicionales en terminal_core/build.gradle.kts.
    2. Compilar libtermux_exec y terminal_core para cada ABI.
    3. Validar funcionamiento en emulador x86_64 y dispositivos ARM32.

[P3] WakeLock y WifiLock selectivos
  - Estado: Implementado (adquisición y liberación en TerminalService)
  - Descripción: Mejorar la gestión de bloqueos de suspensión para no
    mantener WakeLock indefinidamente, sino adquirirlo solo cuando la
    terminal esté ejecutando procesos en primer plano o tareas críticas.
  - Tareas:
    1. Agregar lógica de adquisición bajo demanda basada en actividad.
    2. Liberar WakeLock cuando la app pase a segundo plano sin procesos hijos.
    3. Configurar tiempo de espera máximo configurable.

[P3] Extracción nativa de rootfs con bsdtar
  - Estado: Implementado (RootfsDecompressor, integrado en RootfsManager)
  - Descripción: Priorizar la extracción mediante libbsdtar.so cuando esté
    disponible, con fallback automático al método Java (Apache Commons Compress).
  - Tareas:
    1. Integrar RootfsDecompressor en el flujo de instalación de RootfsManager.
    2. Medir la diferencia de rendimiento entre bsdtar nativo y Java.
    3. Empaquetar libbsdtar.so en jniLibs.

[P3] Manejo de señales SIGSYS (seccomp)
  - Estado: Pendiente (actualmente desactivado vía PROOT_NO_SECCOMP=1)
  - Descripción: Investigar la implementación de un manejador SIGSYS que
    permita mantener seccomp activo para mayor seguridad, atrapando las
    violaciones de llamadas al sistema y simulando ENOSYS como lo describe
    la arquitectura de PRoot.
  - Tareas:
    1. Investigar si PRoot ya maneja SIGSYS internamente.
    2. Evaluar alternativas: policy seccomp personalizada vs PROOT_NO_SECCOMP.
    3. Documentar las llamadas al sistema bloqueadas por Android 14+.
